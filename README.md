# 🏥 Hospital Emergency Room Dashboard | Microsoft Excel

## 📌 Project Overview
This project focuses on analyzing hospital emergency room (ER) data using Microsoft Excel. An interactive dashboard was developed to monitor patient visits, waiting times, satisfaction scores, admission status, and department referrals.

The dashboard helps transform raw hospital data into meaningful insights for understanding emergency room performance and patient experience.

## 🎯 Project Objectives
- Monitor daily patient visits and emergency room activity.
- Analyze average patient waiting time.
- Evaluate patient satisfaction scores.
- Understand admission and non-admission patterns.
- Identify patient demographics and department referral trends.
- Track the percentage of patients attended within 30 minutes.

## 📊 Key Performance Indicators (KPIs)

| KPI | Description |
|---|---|
| Number of Patients | Total number of patients visiting the emergency room. |
| Average Wait Time | Average time patients wait to receive medical attention. |
| Patient Satisfaction Score | Average patient satisfaction rating. |

## 📈 Dashboard Features & Visualizations

1. **Patient Admission Status:** Displays admitted vs. non-admitted patients.
2. **Patient Age Distribution:** Groups patients into different age categories.
3. **Timeliness Analysis:** Measures the percentage of patients attended within 30 minutes.
4. **Gender Analysis:** Shows the distribution of male and female patients.
5. **Department Referrals:** Identifies the departments receiving the highest number of patient referrals.
6. **Daily Trends:** Uses area sparklines to monitor patient visits, waiting times, and satisfaction scores.
